# 像素地牢 V2 改进说明

## 🎯 主要改进

基于原版Pixel Dungeon的真实界面，V2版本进行了全面重构和改进。

---

## 1. 🖼️ 界面布局（完全重新设计）

### V1 问题：
- ❌ UI布局不符合原版风格
- ❌ 状态栏过于简陋
- ❌ 缺少快捷栏
- ❌ 控制按钮位置不合理

### V2 改进：
- ✅ **顶部状态栏**：
  - 角色头像（48x48）
  - 生命值条（渐变红色）
  - 经验值条（渐变绿色）
  - 等级、深度、攻击、防御信息

- ✅ **中间游戏区域**：
  - 自适应Canvas画布
  - 响应式尺寸调整

- ✅ **底部快捷栏**：
  - 5个物品快捷槽
  - 像素风格边框
  - 支持键盘1-5快速使用

- ✅ **侧边功能按钮**：
  - 背包按钮（带弹窗）
  - 搜索按钮

- ✅ **移动控制**：
  - 3x3方向按钮
  - 支持8方向移动

---

## 2. 🗺️ 地图渲染系统（完全重写）

### V1 问题：
- ❌ 使用纯色填充方块
- ❌ 没有纹理和细节
- ❌ 墙壁没有立体感
- ❌ 地形单调

### V2 改进：

#### 墙壁系统：
```javascript
WALL_TOP (墙顶)：
- 亮灰色 (#6a6a6a)
- 带内部阴影效果
- 表示墙壁的顶部

WALL (墙侧)：
- 深灰色 (#4a4a4a)
- 双层颜色营造立体感
- 表示墙壁的侧面
```

#### 地板：
- 基础深灰色 (#3a3a3a)
- 添加随机纹理点
- 不再是单一纯色

#### 草地系统：
```
GRASS (普通草)：
- 深绿色基底 (#2a4a1a)
- 浅绿色细节点

HIGH_GRASS (高草)：
- 更深的绿色 (#1a3a0a)
- 4个草叶纹理
- 影响视野（可扩展）
```

#### 水面：
- 蓝色基底 (#1e90ff)
- **实时波动动画**（基于sin函数）
- 白色高光效果
- 半透明层次

#### 楼梯：
- 深灰色地板
- 金色阶梯纹理
- 4级台阶设计

---

## 3. 👁️ 视野系统（核心修复）

### V1 问题：
- ❌ 只有"可见"和"不可见"两种状态
- ❌ 没有"已探索"的概念
- ❌ 战争迷雾效果不正确

### V2 改进：

#### 三层可见性系统：

```javascript
Cell {
    terrain: TERRAIN_TYPE,
    discovered: boolean,  // 是否曾经探索过
    visible: boolean      // 当前是否可见
}
```

#### 渲染逻辑：
```
未探索区域 (!discovered)：
└─> 完全黑色，什么都不显示

已探索但不可见 (discovered && !visible)：
└─> 40% 透明度的暗色版本
    - 可以看到地形结构
    - 颜色较暗
    - 无实体显示

当前可见 (visible)：
└─> 100% 不透明，完整渲染
    - 亮色地形
    - 显示所有实体
```

#### FOV计算：
- 使用欧几里得距离
- 视野半径：5格
- 圆形视野范围
- 实时更新

## 4. 🎮 精灵渲染系统

### V1 问题：
- ❌ 实体是简单的纯色方块
- ❌ 没有阴影
- ❌ 没有细节

### V2 改进：

#### 通用特性：
- ✅ **所有实体都有阴影**：
  - 椭圆形阴影
  - 30%透明度黑色
  - 位于实体底部

#### 玩家渲染：
```
组成：
├─ 蓝色身体 (#4af)
├─ 肤色头部 (#fdb)
└─ 灰色武器 (#ccc)

细节：
- 不填满整个图块
- 居中显示
- 有层次感
```

#### 怪物渲染：
```
组成：
├─ 根据类型的颜色
│   ├─ 老鼠: 棕色 (#8b4513)
│   ├─ 螃蟹: 红色 (#ff6347)
│   └─ BOSS: 紫色 (#a0f)
├─ 红色眼睛（2个）
└─ 动态血条（受伤时显示）

血条：
- 深红色背景
- 红色填充
- 宽度表示HP百分比
- 显示在怪物上方
```

#### 物品渲染：
```
组成：
├─ 金色圆形底座 (#ffd700)
└─ 黄色十字图案 (#ff0)

特点：
- 圆形设计
- 区别于方形实体
- 易于识别
```

## 7. 📊 技术优化

### 性能：
- ✅ 按需渲染（只渲染可见区域）
- ✅ 使用`requestAnimationFrame`
- ✅ Canvas尺寸优化

### 代码结构：
```
新增类：
├─ Cell (地图单元格)
│   ├─ terrain
│   ├─ discovered
│   └─ visible
│
└─ Renderer (独立渲染器)
    ├─ drawTile()
    └─ drawEntity()
```

### 分离关注点：
- 地图生成 → `MapGenerator`
- 渲染逻辑 → `Renderer`
- 游戏逻辑 → `Game`
- 实体系统 → `Entity` 继承链
