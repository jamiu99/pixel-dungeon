# 像素地牢 Web版 - 项目总结

## 📌 项目概览

本项目是基于经典 Roguelike 游戏 **Pixel Dungeon** 的 Web 版复刻，使用纯 HTML5/Canvas/JavaScript 实现，无需任何外部依赖库。

**项目特点：**
- ✅ 完整汉化（所有UI和文本）
- ✅ 单文件 HTML（可直接在浏览器打开）
- ✅ 完整游戏逻辑（地图生成、战斗、升级等）
- ✅ 响应式设计（支持桌面和移动端）
- ✅ 详细文档（使用说明、资源清单、替换指南）

## 🎮 核心功能实现

### 1. 地图生成系统
- **算法**: Room-Based + Corridor（房间+走廊）
- **特性**:
  - 随机生成 6-9 个房间
  - 自动连接相邻房间
  - 添加草地等装饰元素
  - 放置楼梯、怪物、物品

### 2. 战斗系统
- **机制**: 回合制战斗
- **计算**:
  ```
  实际伤害 = max(1, 攻击力 - 防御力)
  攻击力 = random(攻击最小值, 攻击最大值)
  ```
- **经验系统**:
  - 击败怪物获得经验
  - 经验累积升级
  - 升级提升属性

### 3. 角色系统
```javascript
玩家初始属性:
- 生命值: 20 HP
- 攻击力: 2-6
- 防御力: 0
- 等级: 1

升级成长:
- 每级 +5 HP
- 攻击 +1~+2
- 防御 +1
```

### 4. 怪物AI
- **行为模式**:
  1. 检测玩家距离（视野范围6格）
  2. 相邻则攻击
  3. 否则向玩家移动（简单路径追踪）

### 5. 物品系统
- 当前实现: 生命药水（恢复10 HP）
- 可扩展: 武器、护甲、卷轴、魔杖等

### 6. 视野系统
- **实现**: 基于曼哈顿距离的战争迷雾
- **范围**: 6格半径
- **效果**: 超出视野的区域被遮罩

## 📊 技术实现细节

### Canvas 渲染流程

```javascript
render() {
    1. 清空画布
    2. 计算相机位置（跟随玩家）
    3. 渲染地图图块
        ├─ 遍历地图数组
        ├─ 根据地形类型绘制
        └─ 应用视野遮罩
    4. 渲染物品（在视野内）
    5. 渲染怪物（在视野内）
        └─ 绘制血条（如果受伤）
    6. 渲染玩家
        └─ 绘制高亮框
}
```

### 输入处理

```javascript
输入源:
├─ 键盘事件
│   ├─ 方向键/WASD → 移动
│   ├─ 空格键 → 等待
│   └─ 数字键1-9 → 使用物品
└─ 鼠标/触摸事件
    └─ 点击屏幕按钮 → 移动
```

### 游戏状态管理

```javascript
Game State:
├─ map: 二维数组（地形数据）
├─ player: 玩家对象
├─ monsters: 怪物数组
├─ items: 物品数组
├─ depth: 当前楼层
└─ running: 游戏运行状态
```
